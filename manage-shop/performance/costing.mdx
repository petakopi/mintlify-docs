---
title: "2. Assign ingredient costs"
description: "Link products to recipes, replace ingredients, and check option costs."
---

**Outcome:** each menu selection has an explainable ingredient cost.

Before starting, [save your menu](/manage-shop/performance/menu). Use **Costs & Pricing → Materials** for pack prices and **Recipes** for quantities per serving. The [Materials guide](/manage-shop/costs-and-pricing/items) and [Recipes guide](/manage-shop/costs-and-pricing/recipes) cover those forms.

## Open product costing

Edit your saved product in **Online Store → Products**. Open its **Costing** tab and click **Set up or review product costing**.

The costing page has **Base cost**, **Options**, and **Preview** tabs. Creating a recipe alone does not link it to a product.

## Set the base cost

1. Enter each material’s pack price, pack size, and usable yield in Materials.
2. Create a recipe with the amount consumed per serving.
3. Open **Base cost → Edit base cost** and choose **Recipe** or **Bought-in unit cost**.
4. Select the recipe or enter the cost, then click **Done**.
5. Click **Save product costing** to persist the draft.

**Done** keeps an editor’s changes in the page draft. **Cancel** discards only that editor’s changes. Closing a changed editor asks before discarding. Only **Save product costing** writes the configuration. Menu prices stay unchanged.

Confirm zero only when the cost really is zero. **Not configured** means missing information.

## Configure option costs

Open **Options → Edit options**. Each menu option group has its own tab. Review every offered option:

| Cost rule | Use it when |
| --- | --- |
| No cost change | The choice changes no ingredient cost |
| Add ingredients / portion | The choice adds ingredients, such as an extra shot |
| Replace an ingredient | The choice swaps one base ingredient while keeping its quantity |
| Use a different recipe / unit cost | The choice needs a different complete base recipe or bought-in cost |
| Not configured | You have not decided yet; costing stays incomplete |

### Replace House Blend with Single Origin

For a base recipe containing 18 g of House Blend beans:

1. Keep **House Blend** as **No cost change**.
2. Set **Single Origin** to **Replace an ingredient**.
3. Choose House Blend beans as the source and Single Origin beans as the replacement.
4. Click **Done**, check **Preview**, and save costing.

The replacement uses the original 18 g. Both materials must have the same unit. It affects only the selected base recipe; an extra House Blend shot still uses House Blend. You do not need a separate recipe for this swap.

If several choices replace the same source ingredient, the selection remains incomplete. A source missing from the selected recipe also remains incomplete. Ingredient replacements cannot be repeated more than once per drink.

### Use a different complete recipe

Choose **Use a different recipe / unit cost** when quantities or the complete drink change. Select its full recipe or bought-in unit cost directly under that option.

For combinations of these choices, use **Combined recipe exceptions** in the same editor. Select the exact choices and quantities, add the exception, then configure its complete base cost. Include packaging in the recipe and leave additive extra portions out. The replacement base is costed once; extra portions are added afterward.

## Shared portions

Choose a shared portion beside **Ingredient portion**, or keep ingredients for this product only. **Customize for [product] only** copies the shared lines into the product draft.

Manage shared definitions on **Costs & Pricing → Portions**, using the link beside the selector. Before saving a shared change, review and confirm the listed affected products. Sharing a menu option group alone does not establish ingredient quantities.

## Preview selections

1. Open **Preview** and choose options as a customer would: one-choice groups use radios, multiple-choice groups use checkboxes.
2. Adjust repeated extras and product quantity with the quantity controls.
3. Inspect the base, ingredient replacements, and extras in the breakdown.
4. Repeat for other offered combinations, then save costing.

Costs refresh as choices change. Quantities in the breakdown are per drink. Costs round once per drink, then multiply by product quantity. Unavailable menu options cannot be selected.

An incomplete preview has no total. Resolve the named missing inputs rather than treating its known components as a complete cost. A successful preview proves only that selection, not the entire menu.

## Historical costs

Performance uses the cost at preparation time. If preparation was not recorded, it uses a labelled handover-time estimate. Later price edits do not rewrite recorded past costs.

Adding a mapping today may not fix older orders with missing selection identities or historical inputs. Use [missing-information guidance](/manage-shop/performance/missing-information).

**Ready when:** offered combinations preview with complete costs and the configuration is saved.
